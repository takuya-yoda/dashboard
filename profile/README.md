# 傾向分析DB（profile/）データ辞書

最終更新: 2026-07-08 / 由来: dアニメストア視聴履歴の嗜好分析（別セッションで実施）を最小構成に蒸留したもの。

## 役割
- `profile/` は**人力で数ヶ月に1回だけ更新**する「嗜好モデル」。週次のおすすめ自動生成はこれを**読取のみ**で参照する。
- おすすめの出力先は `recommend/`（週次で自動更新）。

## ファイル
| ファイル | 用途 |
|---|---|
| `profile.json` | 嗜好モデル本体（7軸定義・採点式・判別ルール・クラスタ重心・較正用アンカー） |
| `seen.csv` | 既視聴/既知の除外リスト（フランチャイズ単位）。推薦の重複回避に使用 |
| `archive/` | 元の詳細資料（全作品マスター・レポート・視聴CSV・SQLite等）。来歴保存用、週次では未使用 |

## profile.json スキーマ
- `axes`: 深層7軸 A情念 / B関係 / C手触り / D喪失 / E思弁 / F最適化(負) / G知的密度。
- `scale`: 各軸 0=低,1=中,2=高。
- `scoring.formula`: `A + 1.5*B + C + D + E + G - 2*F`（B核・F忌避を反映した暫定重み）。
- `rule`: 高自認の「好き」を予測する判別ルール文。
- `clusters`: k-means 5クラスタの重心と説明（深層核/思弁/情念関係/雰囲気/最適化なろう）。
- `anchors`: 本人評価＋軸スコアが確定している較正用作品（好む6/好まない4）。
- `notes`: 二層構造・「完走≠本命」等の運用注意。

## seen.csv スキーマ
- 列: `franchise`（シリーズ接尾辞を除去した正規化名） / `status`（watched=視聴済み, interested=気になる） / `example_title`（代表題名）。

## 情報源の区別（重要・全ファイル共通）
- **元データ**: dアニメ画面から取得した事実（視聴状態・話数・各タブ在籍）。
- **本人申告**: `user_rating`（好む/好まない 等、`anchors[].r`）。
- **Claude解釈**: 7軸スコア・クラスタ・判別ルール・適合スコア・推薦。あらすじ/構成は外部DBで確認済みだが軸への当てはめは主観であり事実ではない。

## 更新手順（人力・数ヶ月に1回）
1. Mac Studio ＋ Claude-in-Chrome でdアニメ履歴/コンプリート/気になるを再取得 → `archive/dアニメ_視聴データ.csv` を更新。
2. 新たな本人評価・高自認作を `anchors` に追加（軸スコア付き）。
3. `seen.csv` を再生成（`archive/` の視聴CSVを正規化）。
4. 必要なら重み・クラスタを再最適化（`user_rating` が増えるほど回帰で `scoring` の重みを補正可能）。
5. `version` を更新し push。
