## 深層7軸の採点基準（0=低,1=中,2=高）

- **A 当事者の情念**: 登場人物の感情・切実さの「強度」が物語の中心か。
- **B 親密な関係性**: 二人組/小集団の絆が物語を駆動するか。
- **C 生活・趣味・世界の手触り**: 日常や実学ディテールの濃さ。
- **D 喪失・郷愁・余韻**: もののあはれ的情動の強度。
- **E 思弁の情緒化**: 設定/哲学/SF思弁が人物の情緒に接続しているか。
- **F 制度・権力の最適化（負の指標）**: 内政/支配/社会ゲームの合理運用が主眼か。
- **G 知的密度**: 実学/思弁の情報量（数学・鉱物・物理・オカルト設定など）。

## 情報源の区別（重要）

- **元データ**: dアニメストアの画面から取得した事実（作品名・話数・各タブ在籍）。
- **ユーザー申告**: 本人が明示した評価（user_rating）。
- **Claudeの推論**: 7軸スコア・クラスタ・ティア・推薦は解釈であり事実ではない。あらすじ・構成は外部DB(Wikipedia等)で確認済みだが、軸への当てはめは主観。

## 将来の拡張・統合ガイド

1. **他媒体/他プラットフォームの追加**: 同じ列スキーマで行を追加（platform列で区別）。書籍・Netflix・ゲーム履歴などを同一テーブルに統合可能。
2. **タグ付けの一貫性**: 新作は必ず上記7軸基準で採点。基準を変える場合はバージョンを切って別列に。
3. **再スコアリング**: user_rating が増えるほど、判別軸の重み（現在 B=1.5, F=−2 等）を回帰で最適化できる。
4. **クラスタの再計算**: `analysis34.py` を母集団拡張して再実行。kや重みは要記録。
5. **バージョン管理**: 更新のたびファイル名または列に日付を残す（例: master_works_2026-07-07）。
