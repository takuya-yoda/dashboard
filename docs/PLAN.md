# Dashboard 構築プラン

## 目的
- 自分専用の情報源をまとめたウェブサイト
    - 作品情報
    - ニュース

## 方針
- UI は最小構成
    - セキュリティ対策．外部ツールからの影響から隔離
    - 管理・開発コストを抑える
    - 好みの解析・情報の収集ツールの開発に注力
    - PC / スマホ で表示可能
- 所有者の好みを自動で解析
    - 過去の視聴歴などを参照
    - 試験的に運用．公開しても良い情報だけを解析対象とする
- 解析結果に基づいて自動で情報収集




## 構成
- 常時稼働するこの Mac Studio
- GitHub Pages の公開リポジトリ
- Claude Cowork / Claude Code on web

* Mac Studio 上の Claude Cowork を用いて，Chrome を操作しdアニメストアの視聴履歴を取得
* 取得結果を解析し，嗜好の分析を行う．
* 分析結果を用いて，所有者専用の傾向分析データベースを作成する．ここまでは人力で，例えば数ヶ月に一回程度のみ行う
* データベースに基づいて，ウェブ上から最新の作品を検索し，おすすめの作品リストを作成する．この作業は，例えば週一回の頻度で自動化する
* おすすめ作品リストを用いて GitHub Pages のリストを更新．自動で push する
* 所有者は，ウェブ上から常に自分のおすすめ作品リストを見られる
* GitHub Pages のローカルリポジトリには，ウェブサイトの本体と，おすすめ作品リストのフォルダ，傾向分析の作業フォルダをおく
* Claude Cowork には，傾向分析の作業フォルダと，おすすめ作品リストのフォルダにのみ編集権限を与える
* おすすめ作品リストは最小構成．単なるjsonファイルなど


## 権限
- 嗜好分析，データベース作成は手動
- 分析結果に基づき情報収集，recommend.json 作成は Claude Code on web．これには dashboard リポジトリの編集権限を与える
- 表示部はのデザインは手動
