# Dashboard 構築プラン

## 目的
- 自分専用の情報源をまとめたウェブサイト
    - 作品情報
    - ニュース

## 方針
- UI は最小構成
    - セキュリティ対策．外部ツールからの影響から隔離
    - 管理・開発コストを抑える
    - 好みの解析・情報の収集ツールの開発に注力
    - PC / スマホ で表示可能
- 所有者の好みを自動で解析
    - 過去の視聴歴などを参照
    - 試験的に運用．公開しても良い情報だけを解析対象とする
- 解析結果に基づいて自動で情報収集
